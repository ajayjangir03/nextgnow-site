# U.S. Clears 2.7 GHz Band for 6G Leadership

Quick Summary

  • NTIA approves federal spectrum relocation from 2700-2980 MHz to enable commercial 6G operations with full power transmission
  • 3GPP begins standardization work on n104 band (2.7 GHz) for IMT-2030/6G in Release 21, targeting sub-7 GHz massive MIMO and AI-native air interface
  • New spectrum sharing protocols enable coexistence between federal incumbents and commercial networks through dynamic frequency coordination procedures

Introduction

The 2.7 GHz band (2700-2980 MHz) represents a critical mid-band spectrum allocation for 6G deployment, bridging the gap between capacity and coverage. This frequency range falls within 3GPP's emerging framework for IMT-2030 systems, requiring new radio access technologies and spectrum coordination protocols. The NTIA approval initiates a complex technical migration involving spectrum sharing mechanisms, enhanced interference management protocols, and next-generation radio interface designs that will be standardized in 3GPP Release 21 and beyond. Unlike traditional spectrum clearances, this allocation introduces dynamic coexistence frameworks where federal and commercial systems share spectrum through real-time coordination protocols—a paradigm shift that necessitates new protocol layers and signaling procedures not present in current 5G specifications.

Protocol Overview

  • Standard: 3GPP TS 38.104 (NR Base Station Radio Transmission), TS 38.300 (NR Overall Description), Future TR 38.8xx (6G Study Items)
  • Layer: Physical Layer (Layer 1) and MAC Layer (Layer 2) with new Spectrum Access System (SAS) coordination at control plane
  • Interfaces: NR-Uu (air interface), NG (Next Generation core interface), new SAS-gNB interface for dynamic spectrum coordination
  • Purpose: Define radio characteristics, channel arrangements, and coexistence protocols for 2.7 GHz band (n104) supporting 100 MHz+ channel bandwidths for 6G-Advanced services with dynamic spectrum sharing

Architecture / Nodes Involved

The 2.7 GHz deployment architecture introduces several novel components beyond traditional 5G infrastructure:

Next-Generation NodeB (ng-gNB): Evolution beyond 5G gNB with AI-native beamforming, capable of real-time spectrum sensing and adaptive transmission power control. The ng-gNB implements new spectrum coordination protocols to interface with federal Spectrum Access Systems.

Spectrum Access System-Next (SAS-N): Enhanced version of CBRS SAS architecture, managing interference protection zones for federal incumbents while maximizing commercial spectrum availability. Operates at sub-second timescales for dynamic frequency assignment.

Federal Incumbent Protection Service (FIPS): New network function providing real-time federal system location and operational parameter information to SAS-N for interference calculation and exclusion zone management.

6G Core (6GC): Evolution of 5GC with enhanced Network Slicing capabilities, supporting deterministic latency for spectrum coordination signaling. Includes new Service-Based Architecture (SBA) functions for spectrum policy enforcement.

Distributed Unit (DU) and Centralized Unit (CU): Split architecture with AI/ML processing units for predictive spectrum allocation and interference mitigation. CU manages spectrum coordination signaling while DU handles real-time PHY adaptations.

The architecture implements a three-tier coordination model: macro-level (SAS-N to ng-gNB), meso-level (ng-gNB to ng-gNB coordination), and micro-level (beamformed transmission adaptation based on real-time sensing).

Message Structure

Spectrum Coordination Messages

SPECTRUM ACCESS REQUEST (SAR)

`

Message Type: SAR

IEs:

  • gNB ID (48 bits): Global unique identifier
  • Requested Frequency Range (32 bits): Start/stop frequencies
  • Maximum EIRP (16 bits): Desired transmission power
  • Coverage Area Polygon (variable): Geographic coordinates
  • Time Window (64 bits): Start time, duration
  • Priority Level (8 bits): Service priority indicator
  • Incumbent Protection Requirements (variable): Federal system parameters

`

SPECTRUM ACCESS GRANT (SAG)

`

Message Type: SAG

IEs:

  • Grant ID (64 bits): Unique authorization identifier
  • Authorized Frequency Range (32 bits): Allocated spectrum
  • Authorized EIRP (16 bits): Maximum permitted power
  • Time Validity (64 bits): Grant duration and expiration
  • Restriction Zones (variable): Geographic exclusion areas
  • Coordination Parameters (variable): Interference thresholds
  • Sensing Requirements (variable): Mandatory monitoring parameters

`

DYNAMIC SPECTRUM REPORT (DSR)

`

Message Type: DSR

IEs:

  • gNB ID (48 bits)
  • Measurement Timestamp (64 bits)
  • Spectrum Occupancy Matrix (variable): Per-PRB RSSI measurements
  • Detected Incumbent Signals (variable): Federal system signatures
  • Interference Temperature (variable): Per-channel measurements
  • UE Distribution (variable): Active user density map

`

Air Interface Control Messages (6G-specific)

FREQUENCY ASSIGNMENT COMMAND (FAC)

  • Sent from ng-gNB to UE during connection reconfiguration
  • Contains new carrier frequency, bandwidth, and validity timer
  • Includes spectrum grant expiration for UE awareness

INCUMBENT PROTECTION NOTIFICATION (IPN)

  • Emergency message forcing immediate frequency vacation
  • Requires UE to cease transmission within 50ms
  • Triggers make-before-break handover to alternate frequency

Step-by-Step Flow

Initial Spectrum Acquisition for 6G Network Deployment

  1. Network Planning Phase: Operator submits coverage requirements to SAS-N including desired geographic areas, capacity targets, and service types for 2.7 GHz band deployment.
  1. Federal Coordination: SAS-N queries FIPS database for federal incumbent locations, operational frequencies, and protection requirements within requested coverage area.
  1. Interference Analysis: SAS-N performs Monte Carlo simulations calculating aggregate interference from proposed ng-gNB locations to federal receivers, considering terrain, propagation models, and atmospheric conditions.
  1. Spectrum Grant Issuance: If interference thresholds are met, SAS-N issues SPECTRUM ACCESS GRANT with authorized frequency ranges (potentially non-contiguous), power levels, and operational constraints.
  1. ng-gNB Configuration: Operator configures ng-gNB with granted parameters, including carrier frequency (e.g., 2750 MHz), channel bandwidth (100 MHz), and maximum EIRP (typically 68 dBm/MHz for macro cells).

Dynamic UE Connection on 2.7 GHz Carrier

  1. Initial Access: UE performs cell search on n104 band, detecting Primary Synchronization Signal (PSS) and Secondary Synchronization Signal (SSS) on granted frequency.
  1. System Information Acquisition: UE decodes Master Information Block (MIB) and System Information Blocks (SIB), learning spectrum grant expiration time and incumbent protection requirements.
  1. Random Access Procedure: UE transmits PRACH preamble, receives Random Access Response (RAR), and completes RRC connection establishment.
  1. Capability Exchange: UE reports 6G capabilities including support for rapid spectrum switching, beamformed MIMO, and incumbent detection capabilities.
  1. Data Transmission: Uplink and downlink data flows on 2.7 GHz carrier with continuous spectrum monitoring by both ng-gNB and UE.

Dynamic Spectrum Reconfiguration Event

  1. Federal System Activation: Federal incumbent begins operations within protection zone, detected by FIPS environmental sensors.
  1. Emergency Notification: FIPS sends INCUMBENT ALERT to SAS-N with federal system parameters (frequency, location, protection radius).
  1. Interference Assessment: SAS-N calculates which ng-gNBs must reduce power or change frequency to maintain incumbent protection criteria.
  1. Grant Modification: SAS-N sends updated SPECTRUM ACCESS GRANT to affected ng-gNBs, reducing authorized EIRP or mandating frequency change within 200ms.
  1. Make-Before-Break Handover: ng-gNB signals UEs with FREQUENCY ASSIGNMENT COMMAND, moving active connections to alternate 2.7 GHz channels or different bands (e.g., n77, n79) before ceasing transmission on restricted frequency.
  1. Confirmation and Monitoring: ng-gNB sends COMPLIANCE ACKNOWLEDGMENT to SAS-N, then transmits periodic DYNAMIC SPECTRUM REPORTs proving continued adherence to modified grant.

Key Parameters & Timers

Spectrum Coordination Parameters

MAX_EIRP_n104: Maximum Equivalent Isotropic Radiated Power for 2.7 GHz band

  • Macro cells: 68 dBm/MHz (conditional on distance from federal sites)
  • Small cells: 47 dBm/MHz
  • Indoor: 30 dBm/MHz
  • Dynamically adjusted by SAS-N based on incumbent proximity

PROTECTION_THRESHOLD: Interference limit at federal receivers

  • Critical systems: -129 dBm (aggregate from all commercial sources)
  • Secondary systems: -119 dBm
  • Calculated using International Telecommunication Union (ITU) propagation models

COORDINATION_ZONE_RADIUS: Geographic area requiring enhanced protection

  • Tier 1 (exclusion): 0-5 km from federal site, no commercial operation
  • Tier 2 (coordination): 5-20 km, reduced power operation
  • Tier 3 (notification): 20-50 km, monitoring requirements

Timers for Dynamic Spectrum Management

T_GRANT_VALIDITY: Spectrum access grant duration

  • Default: 86400 seconds (24 hours)
  • Renewable: Automatic renewal if no incumbent conflicts
  • Minimum: 3600 seconds for dynamic allocation scenarios

T_VACATION: Time allowed for frequency vacation after incumbent detection

  • Critical priority: 50 milliseconds (emergency federal operations)
  • Standard priority: 200 milliseconds (scheduled federal usage)
  • Non-real-time: 2000 milliseconds (planned reconfigurations)

T_REPORT_INTERVAL: Periodic spectrum reporting to SAS-N

  • Active transmission: 300 seconds
  • High-traffic periods: 60 seconds
  • Post-reconfiguration: 10 seconds for compliance verification

T_SENSING_CYCLE: Incumbent detection measurement periodicity

  • ng-gNB continuous monitoring: 100 milliseconds
  • UE-assisted sensing: 1000 milliseconds during idle periods
  • Environmental sensors: 10 milliseconds for critical detection

Air Interface Parameters (n104 Band)

CHANNEL_BANDWIDTH_n104: Supported bandwidth options

  • 100 MHz (primary configuration for 6G)
  • 200 MHz (carrier aggregation or contiguous allocation)
  • 400 MHz (future 6G-Advanced target)
  • Subcarrier spacing: 30 kHz (FR1 normal), 60 kHz (extended CP for high mobility)

MAX_UL_POWER: UE maximum transmission power

  • Power Class 1: 23 dBm (smartphones)
  • Power Class 2: 26 dBm (high-power UE)
  • Dynamic power control based on SAS-N restrictions and path loss

FREQUENCY_RANGE_n104: Operating band definition

  • Uplink: 2700-2840 MHz (140 MHz)
  • Downlink: 2840-2980 MHz (140 MHz)
  • TDD alternative: Full 2700-2980 MHz (280 MHz) with dynamic slot allocation

Protocol State Machine (if applicable)

SAS-N Grant State Machine

IDLE State

  • Initial state before spectrum request
  • Transition: Upon receipt of SPECTRUM ACCESS REQUEST → EVALUATION

EVALUATION State

  • SAS-N performing interference analysis and federal coordination
  • Transition:

- Approval → GRANTED

- Denial → REJECTED

- Insufficient data → PENDING (request additional information)

GRANTED State

  • Active spectrum authorization with valid parameters
  • Substates:

- NORMAL_OPERATION: Full grant parameters active

- MONITORING: Enhanced reporting required due to nearby federal activity

  • Transition:

- T_GRANT_VALIDITY expiration → RENEWAL_PENDING

- Federal incumbent detection → SUSPENDED

- Operator release → IDLE

SUSPENDED State

  • Temporary restriction due to incumbent protection requirements
  • ng-gNB must cease transmission or reduce power
  • Transition:

- Incumbent cessation → GRANTED (automatic restoration)

- Timeout (federal operation extended) → REVOKED

RENEWAL_PENDING State

  • Automatic grant renewal evaluation before expiration
  • Transition:

- Approval → GRANTED (new validity period)

- Changed conditions → EVALUATION (new analysis required)

REVOKED State

  • Grant terminated due to compliance violation or persistent incumbent conflict
  • Requires new SPECTRUM ACCESS REQUEST to obtain authorization
  • Transition: After resolution period → IDLE

ng-gNB Operational State Machine

SPECTRUM_ACQUISITION State

  • ng-gNB requesting frequency assignment from SAS-N
  • Awaiting SPECTRUM ACCESS GRANT
  • Cannot serve UEs on 2.7 GHz until granted

NORMAL_OPERATION State

  • Active transmission on authorized frequencies
  • Continuous spectrum sensing and periodic reporting
  • UE connections active with full throughput

POWER_REDUCTION State

  • Reduced EIRP due to incumbent proximity
  • May require UE power reduction or cell edge throughput limitation
  • Maintains connectivity but reduced coverage

FREQUENCY_TRANSITION State

  • Active handover of UEs to alternate frequencies
  • Triggered by INCUMBENT PROTECTION NOTIFICATION
  • Make-before-break procedures to minimize service disruption

SILENT_MODE State

  • Complete cessation of transmission on restricted frequency
  • Triggered when T_VACATION expires without successful UE migration
  • Emergency fallback to protect federal systems

Real-World Deployment Considerations

Spectrum Acquisition Strategy

Operators must develop sophisticated spectrum portfolio management for 2.7 GHz deployment. Unlike traditional exclusive licenses, the dynamic sharing model requires:

Geographic Prioritization: Focus initial SAS-N requests on areas with minimal federal presence. Urban centers may have more federal activity (military bases, government facilities), requiring operators to request lower power allocations or accept smaller coverage areas.

Multi-Band Fallback Architecture: Deploy 2.7 GHz as capacity layer over existing 5G coverage (n77, n41, n71). Ensure ng-gNB and core network can rapidly redirect traffic when spectrum grants are suspended. Typical deployment: n104 for 70% capacity, n77 for 20%, n71 for 10% baseline coverage.

Temporal Usage Patterns: Analyze federal incumbent operational schedules. Some government systems operate during business hours or specific events, creating predictable windows for commercial use. Request time-limited grants during low federal activity periods to obtain higher power authorizations.

Hardware Considerations

Software-Defined Radio (SDR) Requirements: ng-gNB must support wideband tuning across 2700-2980 MHz with rapid frequency switching (<5ms reconfiguration time). Recommend field-programmable gate array (FPGA)-based platforms for real-time spectrum sensing parallel to active transmission.

Antenna System Design: Implement advanced beamforming with null-steering capability to create interference nulls toward federal receiver locations. Typical configuration: 64T64R massive MIMO with per-element digital control, enabling 3D beam pattern shaping.

Spectrum Sensing Frontend: Dedicated RF chain for incumbent detection separate from commercial transmission/reception. Requirements: -130 dBm sensitivity, 50 MHz instantaneous bandwidth scanning, <1 dB frequency accuracy for federal signal identification.

Network Architecture Adaptations

Core Network Slicing: Create dedicated network slices for 2.7 GHz traffic with QoS policies understanding spectrum volatility. Critical services (URLLC) should have guaranteed fallback to stable bands, while eMBB traffic tolerates temporary disruptions during spectrum reconfiguration.

Edge Computing Integration: Deploy Multi-Access Edge Computing (MEC) at ng-gNB sites for real-time AI/ML processing of spectrum sensing data and predictive modeling of federal incumbent activity patterns. Reduces coordination latency with centralized SAS-N.

Transport Network: Ensure fronthaul/midhaul has sufficient capacity for enhanced spectrum reporting. Each ng-gNB generates 10-100 Mbps of telemetry data during high-activity periods. Consider dedicated VLANs for SAS-N coordination traffic separate from user plane.

Operational Procedures

Spectrum Grant Management: Establish Network Operations Center (NOC) procedures for monitoring grant status across all ng-gNB sites. Implement automated alerting when grants approach expiration or suspension occurs. Recommend staffing 24/7 spectrum coordinators initially until operational patterns stabilize.

Performance Monitoring: Track new KPIs beyond traditional 5G metrics:

  • Spectrum availability percentage (target >95% in non-federal areas)
  • Mean time between forced reconfigurations (target >12 hours)
  • Successful vacation rate (target >99.9% within T_VACATION)
  • Grant renewal failure rate (target <0.1%)

Coordination Testing: Conduct quarterly exercises with NTIA and federal agencies to validate protection procedures. Simulate federal incumbent activation and measure commercial network response time and interference levels.

Regulatory Compliance

Record Keeping: Maintain detailed logs of all spectrum grants, reconfigurations, and compliance reports for minimum 3 years. FCC may audit to verify adherence to protection requirements and proper SAS-N coordination.

Interference Resolution: Establish rapid response team for reported federal interference incidents. Must investigate within 24 hours and implement corrective actions within 72 hours or face potential spectrum access suspension.

Continuous Certification: ng-gNB equipment requires specific certification for n104 band operation including demonstrated incumbent detection capability, vacation time compliance, and proper SAS-N protocol implementation.

Troubleshooting Tips

Problem: Frequent Spectrum Grant Suspensions

Symptoms: ng-gNB receives repeated INCUMBENT PROTECTION NOTIFICATIONS, forcing UE handovers to alternate frequencies multiple times per hour.

Diagnosis Steps:

  1. Analyze DSR logs to identify federal system signatures and activation patterns
  2. Correlate suspension times with known federal operational schedules
  3. Review granted EIRP vs. actual transmission power for potential over-power conditions
  4. Check geographic coordinates in SAR—errors cause incorrect incumbent proximity calculations

Solutions:

  • Request lower EIRP authorization to operate continuously rather than at high power intermittently
  • Adjust antenna downtilt to reduce interference toward federal facilities
  • Implement time-division approach: request high-power grants during predictable federal idle periods
  • If false detections: Recalibrate spectrum sensing thresholds, update federal signal database

Problem: High UE Drop Rate During Frequency Transitions

Symptoms: Connection failures spike when ng-gNB executes make-before-break handover to comply with T_VACATION timer.

Diagnosis Steps:

  1. Measure handover execution time from FREQUENCY ASSIGNMENT COMMAND to UE successful connection on new frequency—should be <150ms for T_VACATION=200ms
  2. Check UE capability reports—older devices may not support rapid 6G spectrum switching
  3. Analyze RRC reconfig
